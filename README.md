Food Image-Based Nutrition Analysis Application (สมาชิกจำนวน 8 คน)
รางวัลที่ได้รับ: รางวัลรองชนะเลิศอันดับ 2 (2nd Place) จาก 41 ทีม ในการแข่งขัน DigiTech Hack the Research (มิถุนายน 2026)

FoodSight เป็นแอปพลิเคชันต้นแบบ (Functional Prototype) ด้านโภชนาการและสุขภาพ ที่ถูกพัฒนาขึ้นเพื่อแก้ปัญหาในชีวิตประจำวันของผู้ป่วยโรคไม่ติดต่อเรื้อรัง (NCDs) เช่น โรคเบาหวาน ความดัน ไขมันในเลือดสูง และโรคไต รวมถึงกลุ่มผู้ที่รักสุขภาพ

ตัวแอปพลิเคชันทำงานโดยใช้ AI วิเคราะห์ภาพถ่ายอาหารไทย เพื่อแสดงข้อมูลโภชนาการและประเมินความเสี่ยงต่อโรคได้ทันที ซึ่งช่วยลดเวลาในการค้นหาข้อมูล ลดความยุ่งยากในการตัดสินใจเลือกมื้ออาหาร และเพิ่มความมั่นใจในการเลือกทานอาหารที่เหมาะสมกับเงื่อนไขสุขภาพของแต่ละบุคคล

หน้าที่และความรับผิดชอบ
รับผิดชอบด้านการวางแผนกลยุทธ์ทางธุรกิจและการวิเคราะห์ตลาด เพื่อประเมินโอกาสและความเป็นไปได้ในการพัฒนาแอปพลิเคชันให้เป็นธุรกิจ

- การวิเคราะห์ขนาดตลาด (TAM/SAM/SOM): ศึกษาและประเมินขนาดตลาด เพื่อกำหนดกลุ่มลูกค้าเป้าหมายและวิเคราะห์โอกาสในการเข้าถึงตลาด
- การวางแผนรูปแบบรายได้ (Revenue Model): ออกแบบแนวทางการสร้างรายได้จากระบบสมาชิก และค่าคอมมิชชันจากร้านอาหาร
- การประมาณการรายได้ (Revenue Projection): จัดทำแบบจำลองประมาณการรายได้ล่วงหน้า 3 ปี โดยพิจารณาจากรูปแบบสมาชิก จำนวนผู้ใช้งาน และการใช้บริการแนะนำร้านอาหาร เพื่อประเมินความเป็นไปได้และความคุ้มค่าทางธุรกิจ
